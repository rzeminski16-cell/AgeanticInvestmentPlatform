Outcomes, refusals, and failures

The copy distinguishes the platform protecting the record from the platform being broken.

The report passed every blocking check.Advisory findings remain visible in final review.
The run stopped before making the next call.Raise the ceiling to permit the remaining work, or leave the run safely stopped.
The whole portfolio total is withheld.One holding has no admissible price. Commissioning research on that listing creates the price record; a subtotal is never presented as the whole book.
The extraction worker stopped unexpectedly.No later phase ran. Open the diagnostic record, then supersede this run after the fault is fixed.
This evidence is not produced yet.The source record will appear after acquisition finishes; opening it now does not mean the run failed.
