{# The page shell. Two things here are load-bearing rather than decorative: * The disclaimer block is part of the shell, not of any individual page, so a page cannot ship without it. * Every asset is served from /static. Nothing is loaded from a CDN: this application is local-first and must work with no internet connection, and a third-party script tag on a page that can reach your database is a supply-chain risk taken for convenience. #} {% import "_shell/icons.html" as shell_icons %} {# `data-theme` is rendered rather than scripted: the cookie is already in hand when the page is built, so the palette is correct in the first byte the browser sees. Absent for `system`, which is what lets `prefers-color-scheme` decide. #} {% block title %}Ageantic{% endblock %} {# The typeface, asked for before the stylesheet that references it — otherwise the browser does not learn it needs the font until it has parsed the CSS, and the page renders once in the fallback and again in Source Sans 3. `crossorigin` even though it is our own origin: fonts are fetched in CORS mode, and a preload without it is a second, separate request rather than a head start. **One file of eight.** The interface face carries most of the text on every page, so it is the one worth a head start. Barlow arrives a beat later and reflows the headings it sets, which is the trade `font-display: swap` exists to make; preloading all three families would spend 83 kB before the first paint to avoid it. Only the latin cut. `latin-ext` is fetched by `unicode-range` on the pages that actually contain those letters, and preloading it would spend 59 kB on every page for characters most of them do not have. #} {# The chrome layer: focus, Escape, the scroll lock.
