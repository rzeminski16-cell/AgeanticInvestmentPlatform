{% endmacro %} {% macro sheet(title="", subtitle="", id="") %} {# The working sheet: `surface`, radius 8px, a 1px ledger boundary, and **no shadow**. Elevation means occlusion rather than importance (§4.3), so an ordinary section does not float. Sheets divide their content with horizontal rules and headings and do not contain grids of smaller cards: a card inside a card is a hierarchy the reader has to decode before they can read anything. Empty, refused and failed sheets keep this exact geometry, so the page does not rearrange when the state changes underneath it. #}
