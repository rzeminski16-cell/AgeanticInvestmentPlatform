{# The provenance badges. ADR 0073. **This file is the only place the label strings may appear.** A test greps every template and fails if one is typed anywhere else, which is the same enforcement ADR 0013 uses for section keys: the required `ref` means a badge cannot be built without somewhere to point, and the grep means one cannot be typed around the macro instead. Both macros take a `ProvenanceRef` and no classes. A caller choosing its own colour is a caller that can render "Calculated" in the palette of "Judged", and the difference between those two is the entire point of showing a badge at all. #} {% macro provenance(ref) %} {# The kind is spelled out as well as coloured. A status carried by colour alone is a status a colour-blind reader does not have. #} {{ ref.kind.value }} {% endmacro %} {% macro confirmation(ref) %} {# Who and when, not a bare "Confirmed" — which invites a reader to supply their own idea of both. `confirmation_text` builds the sentence so no template has to. #} {{ ref.confirmation_text }} {% endmacro %}
