The boundary

A method may add requirements. It cannot remove citations, set a rating, or relax the platform's source rules.

A method adds a section to the report, or adds methodology to an existing one. What a file asks for is composed against the platform's floor, and the editor shows exactly what that composition did — including any line it refused, in the file's own words.
