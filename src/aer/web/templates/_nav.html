{# The sidebar. A loop over `shell.nav` rather than hand-written anchors, so a tool contributes a section from its own module and a test can notice a page no route serves (`aer/web/shell/`). Sections render their labels now that there are five of them: an eighteen-item flat list is a list nobody reads. **One nav element, not two.** The obvious responsive shape is a sidebar on a wide screen and a disclosure on a narrow one, and it is wrong here: rendering the nav twice would put two elements with `id="aer-badge-approvals"` on every page, and an out-of-band swap targets an id — the first would update and the second would sit there showing a stale count for ever. So there is one DOM and CSS moves it: a column beside the content from `md` up, a horizontally scrolling strip above it below that. No JavaScript either way. The "not advice" badge sits beside the product name deliberately: it is the first thing read on every page, not something found at the bottom. #}
